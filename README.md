# Angel Care Network — Homepage

Static one-page marketing site for Angel Care Network, a provider of in-home
companion and personal care in Anne Arundel County, Maryland.

## Structure

- `index.html` — the entire site (markup, styles, and a small vanilla-JS script
  for the hero typing animation and the floating call button)
- `images/` — optimized WebP images
- `favicon.svg` — favicon

No build step. Open `index.html` in a browser, or serve the folder with any
static file server:

```sh
python3 -m http.server 8000
```
